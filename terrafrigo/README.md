# TerraFrigo: воспроизводимый YML-фид

Парсер обходит все страницы трёх согласованных разделов TerraFrigo, а затем
загружает каждую уникальную карточку товара. Результаты запуска:

- `offers.jsonl` — исходные нормализованные данные;
- `feed.xml` — Yandex Market YML для импорта в B24U.

Запуск из этой папки:

```bash
python3 parse_terrafrigo.py
```

Данные цены на публичных карточках нет. B24U при импорте **отбрасывает** все
офферы без тега `<price>` (`FEED_ALL_FILTERED` / «Нет цены»), поэтому в фиде
стоит `<price>0</price>` как заглушка и в описании — «Цена: по запросу».
Реальную сумму не выдумываем. У оффера также есть `available`, `vendorCode`,
`quantity` — как у рабочих карточных фидов.

После публикации:

`https://vinte97.github.io/catalog-feeds/terrafrigo/feed.xml`

В промпте бота: цену `0` не озвучивать как стоимость; говорить «цену уточнит менеджер».
