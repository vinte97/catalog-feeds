# TerraFrigo: воспроизводимый YML-фид

Парсер обходит все страницы трёх согласованных разделов TerraFrigo, а затем
загружает каждую уникальную карточку товара. Результаты запуска:

- `offers.jsonl` — исходные нормализованные данные;
- `feed.xml` — Yandex Market YML для импорта в B24U.

Запуск из этой папки:

```bash
python3 parse_terrafrigo.py
```

Для небольшой проверочной выгрузки можно добавить `--limit 10`. Скрипт не
придумывает цену, наличие, остаток или артикул: на публичных карточках эти
данные не размещены. Основное изображение берётся только из галереи карточки;
дополнительные иллюстрации из описания и похожие товары в фид не попадают.

После публикации репозитория через GitHub Pages адрес фида будет:

`https://vinte97.github.io/catalog-feeds/terrafrigo/feed.xml`
